## 3. STEP-BY-STEP yang kamu perlu lakukan saat balik

### Step 3.1 — Paste Anthropic key ke Railway (5 menit)

State sekarang: tab Chrome kamu ada di Railway LibreChat Variables. Field ANTHROPIC_API_KEY edit terbuka, **value field kosong** (saya sudah hapus placeholder `user_provided`).

**Pilihan A — kalau kamu simpan ANTHROPIC_API_KEY di password manager / Notes:**

1. Buka password manager kamu, ambil ANTHROPIC_API_KEY
2. Tetap di Chrome tab Railway, paste di field (Ctrl+V)
3. Klik **checkmark ✓** di kanan field
4. Konfirm "saved" status

**Pilihan B — kalau lupa, generate baru di Anthropic Console:**

1. Buka tab baru: https://console.anthropic.com/settings/keys
2. Klik **"Create Key"** → kasih nama `LibreChat Railway` → Copy key (cuma muncul sekali)
3. Kembali ke tab Railway, paste, klik ✓
4. (Catatan: key baru INI cuma untuk LibreChat. Key Vercel/Gerai PWA tetap untuk Atmaja, tidak diganggu.)

### Step 3.2 — (Optional) Add other API keys

Sambil di Railway Variables, tambah optional:

- **GOOGLE_KEY** — kalau mau pakai Gemini di LibreChat. Get free di https://aistudio.google.com/apikey (free tier 1500 req/hari Gemini Flash).
- **OPENAI_API_KEY** — kalau mau pakai GPT-5/5.5. Copy dari Vercel env (sama key untuk image gen).
- **DEEPSEEK_API_KEY** — kalau mau eksperimen murah. Top-up $5 di https://platform.deepseek.com/api_keys.

Cara: klik **"+ New Variable"**, nama variable + value, Save. Atau pakai **Raw Editor**, tempel block:

```env

OPENAI_API_KEY=sk-proj-...
DEEPSEEK_API_KEY=sk-...
```

Setelah env vars di-update, Railway biasanya auto-redeploy. Kalau tidak:

Tunggu ~2-3 menit build.

### Step 3.4 — Login admin pertama (2 menit)
